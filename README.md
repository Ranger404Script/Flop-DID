# آموزش ساخت DID (did:key) برای Technocore / FLOP

راهنمای ساده و فارسی برای ساخت هویت **Ed25519 did:key** به‌صورت امن و لوکال، برای آماده‌شدن برای تست‌نت و ایردراپ پروژه‌ی FLOP (Flop Labs).

> ⚠️ **هشدار:** این مخزن غیررسمی است و ارتباطی با Flop Labs ندارد. ساخت DID **ایردراپ را تضمین نمی‌کند**. طبق اعلام‌های عمومی، سهم ایردراپ به فعالیت در تست‌نت بستگی دارد. فقط به اطلاعیه‌های رسمی @flop_labs و @CryptoHayes اعتماد کن.

---

## DID چیست؟

یک DID در اینجا فقط یک جفت‌کلید Ed25519 است که کلید عمومی‌اش به شکل شناسه‌ای مثل زیر درآمده:

```
did:key:z6Mk...
```

- **کلید خصوصی** را فقط خودت داری و با آن پیام‌ها را امضا می‌کنی.
- **DID (کلید عمومی)** را می‌توانی علنی کنی. هرکس می‌تواند امضای تو را با آن راستی‌آزمایی کند.

ساختار DID: کلید عمومی خام ۳۲ بایتی + پیشوند multicodec (`0xed01`) → رمزگذاری base58btc → افزودن پیشوند `z` → افزودن `did:key:`. به همین دلیل همه‌ی DIDهای Ed25519 با `z6Mk` شروع می‌شوند.

## مرحله ۱: ساخت کلید

```bash
python3 generate_did.py init
```

- یک رمز عبور قوی (حداقل ۸ کاراکتر) می‌پرسد.
- کلید خصوصی را **رمزنگاری‌شده** در `identity.pem` ذخیره می‌کند (دسترسی فایل `600`).
- DID عمومی‌ات را چاپ می‌کند.

> **فقط یک بار اجرا کن.** اگر `identity.pem` وجود داشته باشد، اسکریپت اجازه‌ی ساخت دوباره نمی‌دهد تا کلیدت به‌اشتباه از بین نرود.

دیدن دوباره‌ی DID:

```bash
python3 generate_did.py did
```

---

## مرحله ۲: پشتیبان‌گیری (مهم‌ترین مرحله)

اگر `identity.pem` یا رمز عبور را گم کنی، کنترل هویتت را از دست می‌دهی و احتمالاً نمی‌توانی ایردراپ را دریافت کنی.

- از `identity.pem` در چند جای مختلف نسخه بگیر (فلش، هارد خارجی، مدیر رمز عبور).
- رمز عبور را جدا از فایل نگه دار.
- پشتیبان را فقط آفلاین یا رمزنگاری‌شده ذخیره کن.

---

## مرحله ۳: ثبت DID در رجیستری و check-in

این مرحله روی سرویس Technocore (`technocore.chat`) انجام می‌شود:

1. DID عمومی را در رجیستری Technocore منتشر کن.
2. یک پیام check-in با کلید خصوصی امضا کن و بفرست.

**جزئیات API و فرمت دقیق امضا ممکن است تغییر کنند**، پس این مراحل را طبق آموزش و ابزار **رسمی** Flop Labs (و امضاکننده‌ی رسمی در مخزن‌های خودشان) انجام بده و از کپی‌کردن اسکریپت‌های ناشناس خودداری کن. هر ابزاری که از تو **کلید خصوصی** بخواهد، قبل از استفاده باید کد منبعش را کامل بخوانی.

## قوانین امنیتی

| ❌ هرگز | ✅ همیشه |
|---|---|
| `identity.pem` را روی GitHub بگذار | `.gitignore` را از همان ابتدا داشته باش |
| کلید یا رمز را به کسی بده (حتی ادمین و پشتیبان ادعایی) | فقط کلید **عمومی** (DID) را به اشتراک بگذار |
| در سایت‌های ناشناس کلید را وارد کن | کلید را روی دستگاه خودت نگه دار |
| ایردراپ را «تضمینی» فرض کن | اطلاعیه‌های رسمی را دنبال کن |

تیم واقعی پروژه هیچ‌وقت کلید خصوصی تو را نمی‌خواهد. هر پیام مستقیمی که کلید، seed یا رمز بخواهد کلاهبرداری است.
